SDC Trustees — Reference Template

SDC Trustee Appointment Minutes Template

For the SDC formation committee — reference template, published 1 Nov 2026.

Back to SDC Trustees.

Purpose

Why this template exists.

Each minuted decision to appoint a Trustee gets a unique minute reference. The issuer enters that reference before a one-time Trustee invite can be issued — an invite is refused without a valid reference, so these minutes are the start of the audit trail. The trail runs: minute → invite → event record.

01One minute item per nominee. One appointment decision produces one reference, which authorises one invite.
02Decision date plus minute reference. These are the two parts of the committee approval reference in the YFPCloud Cutover Plan. The minute reference has the decision date built in, so the two are checked against each other.
03The approving body is the SDC formation committee (decision Q1): Staalbaek Ltd advisory board members plus external advisors. Benjamin Williamson-Westerman issues invites only after the committee has agreed and confirmed.
04No invite is issued before the SDC–YFP data processing agreement exists (decision Q3). Every appointment minute records the agreement reference.

This template records decisions. It is not legal advice. SDC's constitution as a charitable incorporated organisation decides who may appoint Trustees and how. Check it with SDC's adviser before first use.

Reference Format

How a minute reference is built.

A minute reference has the form SDC-FC-YYYYMMDD-Mnn, for example SDC-FC-20261105-M04. That example is item 4 of the formation committee meeting on 5 Nov 2026.

PartMeaningRule
SDCOrganisationAlways SDC
FCApproving body: SDC formation committeeFixed code; a new body needs a new code (see Open questions)
YYYYMMDDMeeting date, which is the decision dateMust equal the decision date entered at issuance
MnnMinute item number, two digitsUnique within the meeting; numbered in agenda order

The meeting reference is the same string without the item number: SDC-FC-20261105.

The committee approval reference has two parts:

01decision date 2026-11-05
02minute reference SDC-FC-20261105-M04

The issue form checks that:

01the reference matches the pattern SDC-FC-<8 digits>-M<2 digits>;
02its date equals the decision date;
03the decision date is not in the future;
04the reference has not already been used by another invite, unless that invite was revoked or expired unused.

A reference is never reused for a different person, even after a failed invite. A re-issue for the same person cites the original minute.

Open Questions

What's still being decided.

01Which meetings approve appointments? This is a wording question left open for the SDC formation committee to decide (noted 1 Nov 2026). The request asked for a "trustees meeting" template; decision Q1 names the formation committee. If SDC's trustee board later approves appointments, it needs its own code, such as SDC-TB. Until the committee decides, Q1 stands and only SDC-FC is accepted.
02Where this template will live. It is to be a template inside SDC's shared workspace, in an area the Trustees and SDC groups can see. The exact location will be decided later.
03Data processing agreement reference format. Not yet defined; treated as free text until a format is agreed.
04Does a removal also need a minute reference? A reference is required only for issuing an invite. This template supplies one for removals too.
